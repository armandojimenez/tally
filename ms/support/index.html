Jawapan pantas

Bagaimana untuk memulihkan Tally Pro pada telefon baharu?
Pasang Tally, buka Tetapan dan ketik Pulihkan pembelian. Gedung mengesahkan pembelian dan semuanya milik anda semula. Pada iPhone, Perkongsian Keluarga aktif, jadi pembelian dalam kumpulan keluarga anda turut dikira.
Bagaimana untuk menjadikannya senyap sepenuhnya?
Buka Tetapan dan hidupkan Mod senyap. Ia mematikan bunyi klik dan getaran sekali gus. Kliknya tidak pernah memotong muzik anda. Ia cuma menumpang di atasnya.
Saya terketik dua kali.
Ketik Buat asal, di bawah nombor. Ia menolak satu. Sifarkan mengembalikan kiraan ke sifar untuk set seterusnya.
Di mana kiraan saya disimpan?
Pada telefon anda, dan tiada di tempat lain. Tiada akaun dan tiada awan, jadi tiada tempat untuk log masuk dan tiada apa-apa untuk dipadam pada mana-mana pelayan.
Bolehkah saya mula dari nombor selain sifar?
Dengan Tally Pro, sunting pembilang dan taip sebarang nombor permulaan, atau lompat ke nombor baharu di tengah set.
